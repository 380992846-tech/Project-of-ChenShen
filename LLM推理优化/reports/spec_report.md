# 投机解码吞吐基准

- target 参数：`984,192`；draft 参数：`60,480`
- 生成 `96` token，`γ=4`，`3` 轮取平均

| 方式 | 吞吐 (tokens/s) | 每 token 的 target 前向次数 |
|------|-----------------|------------------------------|
| target (KV cache) | 255.8 | 1.00 |
| speculative | 243.0 | 0.20 |

**墙钟加速比**：0.95×（CPU 小模型，波动较大）

## 关键指标
- 平均每轮接受草稿数：**5.00**（最高 γ+1=5）
- **每 token 的 target 前向次数**：投机把 target 前向从每个 token 1 次降到 0.20 次——这是与 GPU 无关的**算法层收益**，在真实大模型上直接对应 ~5.0× 的 target 计算量下降。

## 说明
- 投机解码用更快的 draft 猜 `γ` 个候选，target 一次并行验证，接受率越高，每轮 target 前向产出的 token 越多；
- 墙钟加速取决于 **draft 相对 target 的加速比** × **接受率**：draft 不够快（如 CPU 小模型）时墙钟收益有限且噪声大；
- 正确性由精确拒绝采样保证（draft==target 时输出与 target 完全一致，测试覆盖）。
