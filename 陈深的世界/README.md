## 技术说明

- **单文件应用**：所有 HTML/JS/CSS 内嵌，无需构建，直接浏览器打开。
- **图片素材**：存于仓库 `photos/`，游戏通过 **jsDelivr CDN** 加载（CDN 链接钉在某 commit，缓存稳定；改 `photos/` 目录会断图）。
- **体积**：《陈深的故事 V5》约 1.2MB，首次加载较慢；如需优化可做图片懒加载 / 资源外置（见 `docs/架构说明.md`）。
