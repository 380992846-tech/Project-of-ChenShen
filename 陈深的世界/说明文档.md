# 陈深 · 人间烟火（典藏版）

把《陈深的世界》（房间探索）与《陈深的故事 V5》（互动叙事）合并为**一个游戏**，
并本地化全部图片、优化性能、封装为 Windows EXE 的整合工程。

> 📍 **当前位置：`E:\陈深-人间烟火`**（整体已迁移到 E 盘）。
> 📦 成品：`E:\陈深-人间烟火\game\release\陈深-人间烟火-win32-x64\陈深-人间烟火.exe`

## 本版（2026 版）更新
- **体积瘦身**：项目整体从 834MB → **473MB**（省约 360MB）。
  - 图片**全部保留**，仅压缩：长边压到 1800、质量 75 → 图片 150MB → **104MB**（asar 153→107MB）。
  - 删除 `node_modules`（270MB 构建工具，成品不需要；重新构建时 `npm install` 即可恢复）。
- **新增玩法**（主菜单）：
  - 🌙 **开场叙事**：进入时一段可跳过的「鲸鱼昼夜」开场动画（点击 / 回车跳过）。
  - 🌙/☀️ **昼夜主题切换**：主菜单可在「夜·月潮」与「昼·水晶工坊」之间切换，偏好自动记忆。
- **体验优化**：世界游戏底部房间切换栏改为两行，支持鼠标滚轮纵向滚动。

## 一、做了什么

### 1. 合并为单一游戏
- 新增统一入口 **`index.html`**（主菜单「陈深 · 人间烟火」）：
  - 🌌 **他的世界** —— 进入房间探索玩法
  - 📖 **他的故事** —— 进入章节叙事玩法
  - 🖼 **回忆图鉴** —— 一个可浏览全部 79 张私人照片的收藏画廊
  - `Esc` / 左上角按钮可随时返回主菜单
- 两个游戏经 iframe 隔离嵌入，互不干扰、各自存档独立。

### 2. 图片下载 + 本地化（离线可用）
- 从 GitHub `Project-of-ChenShen/photos` 下载 **79 张私人照片** → `photos/`
- 从各远程图源补齐通用素材 → `assets/`（带 URL 哈希命名 + `url_map.json` 映射）
- 用 `build_localized.js` 把两个游戏里所有**能本地化的图片 URL 替换为本地相对路径**：
  - 《故事》已做到 **0 张远程图片，全离线**
  - 《世界》所有私人照片 + 主要房间壁纸已本地化；个别通用背景图保留在线（离线时游戏自带
    CSS 插画回退，画面不破碎）

### 3. 性能优化
- **图片压缩**：长边 >2048 缩到 2048、JPEG 质量 82、PNG 重新优化 →
  `243MB → 115MB`（体积减半，`compress_images.py`）
- 全部素材随 EXE 内置（asar），**无需联网即可游玩**
- 游戏素材统一走本地加载，预加载更快、无网络抖动

### 4. 体验优化（按反馈）
- **底部房间切换栏改为两行**：`#roomChips` 由单行横滚改为 `flex-wrap` 换行 + 居中，
  支持鼠标滚轮纵向滚动（原单行横滚鼠标滚轮拖不动，现已修复）。

探索方向（《世界》）
1. **跨房间彩蛋联动**：在某房间收集的道具可打开另一房间的隐藏入口（形成解谜链）。
2. **收集图鉴图鉴化**：把散落彩蛋做成「记忆图鉴」，收集满解锁隐藏房间/结局动画。
3. **昼夜/天气系统**：同一房间不同时段呈现不同壁纸与 BGM。
4. **成就徽章墙**：探索度、全收集、限定操作（如摸猫 10 次）解锁专属徽章。

叙事方向（《故事》）
5. **好感/信任深度联动**：不同分支结局解锁专属角色小传与隐藏章节。
6. **选择回溯/章节重玩**：通关后可在「回忆」里回看每条路线的关键抉择点。
7. **结局图鉴**：把多结局做成可收集的「星空结局图」，收集进度可视化。

通用
8. **跨模式存档桥接**：世界收集的照片/成就，在故事中解锁隐藏彩蛋（需统一存档 key）。
9. **开场叙事**：主菜单增加一段可跳过的「鲸鱼昼夜」开场动画。

## 三、构建方法

> 重新构建前需先恢复构建工具（node_modules 已被删除以瘦身）：
> ```bash
> cd game && npm install
> ```

```bash
# 1) 本地化（重跑时用）
node build_localized.js

# 2) 压缩图片（可选，缩小体积）
python compress_images.py

# 3) 打包 EXE
node node_modules/electron-packager/bin/electron-packager.js \
  . "陈深-人间烟火" --platform=win32 --arch=x64 --out=release \
  --overwrite --asar --icon=app.ico --prune=true
```

产物：`release/陈深-人间烟火-win32-x64/陈深-人间烟火.exe`（绿色免安装）。
