# 量化策略（聚宽 · 回测）

> A 股/ETF 量化交易策略家族，基于**聚宽（JoinQuant）**平台，含一套可本地运行的回测脚本。

## 策略一览

| 文件 | 标的 | 信号 | 风控 | 运行环境 |
|------|------|------|------|----------|
| `joinquant_v18.py` | 沪深300 ETF | **随机森林**分类 | 止损/回撤/超期 | 聚宽平台 |
| `quant_v21.py` | 沪深300 ETF | 技术规则（RSI/ATR/背离） | 动态止损、分批止盈 | 聚宽平台 |
| `quant_xgboost_shap.py` | 中证500 | **XGBoost + SHAP**、增量学习 | 概率校准阈值 | 聚宽平台 |
| `quant_v14.py` | 多资产（沪深300/国债/黄金） | 随机森林 + **风险平价** | 目标波动率、止损止盈 | ✅ **可本地回测** |
| `quant_features.py` | — | 纯函数特征工程（供单测） | — | 任意环境 |
| `金融数学.py` | — | GBM/OU、ARCH、协整等计量分析 | — | 本地 |

> ⚠️ 全部为**研究/回测用途**，非投资建议；实盘前需充分验证与风控评估。

## 本地回测（`quant_v14.py`）

`quant_v14.py` 是唯一**不依赖聚宽平台**、可直接本地跑的策略：
多资产数据（yfinance / akshare，失败自动回退模拟数据）→ 特征工程 →
随机森林信号 → 风险平价仓位 → 参数网格搜索找最优 → 输出绩效与诊断。

```bash
pip install numpy pandas scikit-learn matplotlib tqdm yfinance akshare
python 量化策略（聚宽·回测）/quant_v14.py
```

输出指标：总收益率、年化、最大回撤、夏普比率、胜率、盈亏比、卖出原因分布。

## 聚宽平台策略

`joinquant_v18.py`、`quant_v21.py`、`quant_xgboost_shap.py` 为聚宽策略，使用方式：
把脚本内容复制到聚宽研究/回测环境，选择对应标的运行，对比基准（沪深300）。

## 特征工程（`quant_features.py`）

纯函数模块（仅依赖 numpy/pandas），提供 RSI、ATR、收益率/均线/乖离/量比/波动率/趋势
等特征与标签，已被 `tests/test_quant_features.py` 单元测试覆盖，可逐步迁移到各策略复用。

## 回测结果（`quant_v14.py` 实测）

> 数据：沪深300 / 国债ETF / 黄金ETF，2015–2026，2942 个交易日（11.7 年），真实行情。

```
总收益率:   231.86%
年化收益率:  11.33%
最大回撤:   -12.49%
夏普比率:    0.446
胜率:       80.9%
平均盈利:    3.09% / 平均亏损 -1.41%
```

**诊断建议**（脚本自动输出）：超时卖出占比 81% 偏高，且超时交易平均盈利为正
（+2.66%），提示**可适当延长 `max_hold_days`** 以让利润奔跑。

> ⚠️ 该结果为策略在特定参数/区间下的回测，**不代表未来收益**，也非投资建议。
