# 架构与工程说明

> 本文件解释本仓库的组织方式、关键数据流，以及如何复现模型训练。

## 1. 目录总览

| 目录 | 内容 | 说明 |
|------|------|------|
| `大模型/` | Python 代码与训练数据 | Transformer、量化策略、助手、物理/诗词脚本 |
| `小世界/` | 交互式 HTML 游戏 | 《陈深的世界》《陈深的故事》等 |
| `网页作品/` | 各类单文件 HTML | 课表、笔记、面试题库、量化主题页等 |
| `笔记/` | 知识文档 | LLM 技术栈、课程笔记、PDF 参考资料 |
| `photos/` | 游戏图片素材 | 经 jsDelivr CDN 加载 |
| `tests/` | pytest 单元测试 | 当前覆盖 `大模型/quant_features.py` |

## 2. 关键数据流：photos → HTML → CDN

`小世界/` 中的游戏页面（如《我们在一起 V6》）在运行时通过 CDN 加载图片素材：

```
photos/xxx.jpeg  --(提交到仓库)-->  GitHub 仓库路径  --(jsDelivr CDN)-->  浏览器
```

例如：

```
https://cdn.jsdelivr.net/gh/<owner>/Project1@<commit>/photos/<file>.jpeg
```

> ⚠️ **重要**：`photos/` 目录路径被 HTML 内的 CDN URL **直接引用**。改名 `photos/`
> 会**破坏**所有游戏的图片加载。如需调整目录结构，必须同步修改所有 HTML 中的 CDN 链接。

## 3. 模型训练复现（`大模型/complete_ai_toolkit.py`）

字符级 Transformer 的训练数据来自 `大模型/training_data.txt`（语料）与
`大模型/vocab.json`（字符级词表）。

```bash
# 训练（在仓库根目录）
python 大模型/complete_ai_toolkit.py --mode train

# 其他模式
python 大模型/complete_ai_toolkit.py --mode classify   # 文本分类
python 大模型/complete_ai_toolkit.py --mode generate   # 条件生成
python 大模型/complete_ai_toolkit.py --mode rag        # RAG 问答
python 大模型/complete_ai_toolkit.py --mode quantize   # INT8 量化
python 大模型/complete_ai_toolkit.py --mode dashboard  # Streamlit 监控
```

模型权重（`*.pth` 等）已通过 `.gitignore` 排除，不会进入版本库，可随时重新训练生成。

## 4. 量化模块

- `大模型/joinquant_v18.py`、`quant_v21.py`、`quant_xgboost_shap.py` 为**聚宽（JoinQuant）**
  平台策略，需在聚宽研究环境运行。
- `大模型/quant_v14.py` 为**可本地运行**的回测脚本（yfinance / akshare 拉取数据）。
- `大模型/quant_features.py` 为**纯函数**特征工程模块（无行情依赖），
  便于单元测试；策略脚本未来可逐步迁移复用它。

## 5. 工程设施

- `pyproject.toml` —— 项目元数据 + ruff / pytest / mypy 配置
- `.github/workflows/ci.yml` —— 每次 push/PR 自动跑 lint、单测、编译冒烟
- `.editorconfig` / `.pre-commit-config.yaml` —— 编辑器与提交前规范
- `requirements.txt` —— 依赖清单（与 `pyproject.toml` 中 [project] 保持一致）

### 本地跑测试与检查

```bash
pip install -e .[dev]   # 安装开发依赖（含 pytest / ruff / mypy）
pytest                  # 运行单元测试
ruff check .            # 静态检查
ruff format --check .   # 格式检查
```
