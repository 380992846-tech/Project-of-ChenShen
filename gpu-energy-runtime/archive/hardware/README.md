# 开源硬件（Open Hardware）

> ⚠️ 再次强调：以下设计用于**受控实验台**，不是数据中心机柜。真机柜请勿安装。

## 组件

| 组件 | 规格 | 来源 |
|---|---|---|
| Virgo GPU | 基于 Chisel RTL，约 16nm 工艺；集成于 Chipyard SoC（Vortex GPGPU） | 开源 |
| 3D 打印两相蒸发器 | `AlSi10Mg`，激光粉末床熔融（SLM®280），一体成型无装配点，**600W**、60–80°C | 商用定制 |
| 烤架模块 | 食品级不锈钢 + IR 热电堆感温阵列 | 定制 |
| 冷却工质 | 介电液体（闭式回路） | 市售 |
| 自动翻面机构 | 舵机 + 机械臂，每 45s 翻转 90° | 定制 |

## 热通道隔离（关键安全设计）

```
GPU 核心 (75-85°C) → 3D打印蒸发器 → 热虹吸循环 → 60-80°C 热输出 → 独立烤房
```

- **热端管路引出机柜**：接到走廊/楼顶的"热回收烤房"，**热源与服务器隔离**。
- **闭式换热**：GPU 冷却液走闭式回路，烤架只是**二次热交换器**，**油烟绝不回流服务器**。
- **保大保小逻辑**：温度瞬飙到 90°C 或 UPS 过载时，自动机械臂把食材抬离热源，**优先保算力**。

## 设计文件

- `virgo_evaporator.stl` — 600W 两相热虹吸蒸发器（3D 打印件）
- `grill_assy_v2.f3d` — 食品级烤架 Fusion360 源文件
- `ir_sensor_mount.stl` — IR 热电堆固定支架

## 许可

## 环境效益

- 单材料设计便于回收
- 把 GPU 废热用于食品加工 / 供暖，单位预计减少 25–30% 排放（相对纯电加热）
- 被动散热零主动能耗
