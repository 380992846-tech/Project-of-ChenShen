对话框 · 上下文

核心机制 对话框的本质是 多轮上下文管理。系统通过 System Prompt 设定角色，User/Assistant 消息交替构建记忆。

  • 上下文窗口：当前主流 128K~1M tokens，超出则截断或摘要压缩。
  • 临时喂数据：将文档、表格直接粘贴在提问前，用 ### 或三引号分隔。
  • 结构化输出：要求模型返回 JSON / Markdown，配合 temperature=0.2 提高稳定性。
<|system|> 你是资深AI架构师
<|user|> 请基于以下数据：... 生成总结
上下文注入 Temp / Top-p 窗口管理

ML · 机器学习

基石 大模型基于 深度学习，核心是 梯度下降 与 反向传播。

  • 监督学习：海量文本对 (输入-输出) 训练，学习概率分布。
  • 自监督：掩码语言建模 (MLM) / 自回归 (AR) 预训练。
  • 关键概念：Epoch, Batch Size, Learning Rate, Loss Function (Cross-Entropy)。
loss = cross_entropy(logits, labels)
optimizer.step() # 梯度更新
梯度下降 神经网络 反向传播

NLP · 语言理解

核心任务 分词 → 词向量 → 上下文表征 (Transformer)。

  • Tokenizer：将文本切分为 subword (BPE/WordPiece)，映射为 token id。
  • Embedding：将 token 映射为稠密向量，捕捉语义。
  • Attention：自注意力机制捕获长距离依赖，是大模型的支柱。
tokens = tokenizer.encode("你好大模型") # [101, 234, ...]
embeddings = nn.Embedding(vocab_size, hidden_dim)

训练 · 预训练 & SFT

两阶段 预训练 (PT) 在海量语料上自监督学习，监督微调 (SFT) 用对话数据对齐。

  • 数据规模：PT 需 TB 级文本，SFT 需 10k~100k 高质量对话。
  • 计算资源：PT 需千卡集群，SFT 可用单卡 (QLoRA) 微调。
  • 训练策略：Warmup, 余弦退火, 梯度裁剪, 混合精度 (FP16/BF16)。
# 伪代码
for epoch in range(3):
  for batch in dataloader:
    loss = model(batch)
    loss.backward(); optimizer.step()

调参 · 超参数 & 微调技巧

关键超参数

  • Learning Rate：1e-5 ~ 5e-5 (SFT) ；预热后余弦衰减。
  • Batch Size：受显存限制，可用梯度累积模拟大 batch。
  • Epochs：SFT 通常 2~5 轮，过多会过拟合。
  • LoRA Rank (r)：8~64，越大可学习参数越多，但显存增加。
  • Weight Decay：0.01~0.1，防止过拟合。

微调策略

  • 全量微调：更新全部参数，效果好但昂贵。
  • LoRA / QLoRA：低秩适配，显存节省 70%，效果接近全量。
  • Prompt Tuning：只更新连续 prompt 向量，极轻量。
  • RLHF / DPO：用偏好数据对齐人类价值观。
# LoRA 配置 (PEFT)
lora_config = LoraConfig(r=16, lora_alpha=32, target_modules=["q_proj","v_proj"])

喂数据 · 从清洗到打包

数据清洗 4 步

  1. 去重：删除完全重复或高度相似的问答对。
  2. 格式统一：转义换行/引号，确保 JSON 合法。
  3. 长度裁剪：单条回答 ≤ 2048 tokens (约 1500 汉字)。
  4. 加系统提示：在对话开头插入 system 消息固化风格。
{"conversations": [
  {"from":"system","value":"你是专业客服"},
  {"from":"human","value":"..."},
  {"from":"gpt","value":"..."}]}

打包 & 训练

  • 格式：JSONL (每行一条 JSON) ，非数组。
  • 工具：LLaMA-Factory (推荐) / Axolotl / Unsloth。
  • 数据量：最少 500 条有效样本，低于 100 条基本无效。
  • 验证集：留出 5%~10% 数据监控过拟合。
# 写入 JSONL
with open("train.jsonl","w") as f:

训练调参 · 实践流程

从数据到模型的五步

  1. 数据准备：清洗 → 去重 → 格式统一 → 切 train/val。
  2. 基线跑通：先用默认参数小规模跑 1 轮，确认能收敛、无 NaN。
  3. 粗调：先定 Learning Rate（1e-5~5e-5），再调 batch/epochs。
  4. 细调：LoRA rank、warmup、梯度裁剪、混合精度。
  5. 评估迭代：看 val loss + 实际生成质量，返回第 2 步。

评估 · 防过拟合

评估信号

  • val loss：不降反升 → 过拟合，降低 epoch / 加正则。
  • 生成质量：抽查真实输出，比 loss 更直观。
  • 数据分布：别只看平均 loss，看难例/长尾。
  • 人类偏好：RLHF/DPO 后看 aligned 程度。

防过拟合手段

  • 数据增强/清洗：质量 > 数量，去重去污染。
  • 正则：weight decay、dropout、early stopping。
  • LoRA 小秩：参数更少，泛化更好。
  • 合理 epoch：SFT 通常 2~5 轮。
