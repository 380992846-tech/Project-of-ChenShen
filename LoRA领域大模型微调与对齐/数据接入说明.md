# 真实数据接入说明

两份修复后的脚本仍用**示例/模拟数据**。要训出真正适配你领域的效果，请把示例数据替换成你自己的真实数据。本文给出**数据格式**和**接入方式**。

## 一、SFT 数据（`train_lora.py`）

### 1. 数据格式
推荐统一为 **JSONL**（每行一个对象），字段：

```jsonl
{"system": "你是法律顾问…", "instruction": "什么是不可抗力？", "output": "不可抗力是指…"}
{"system": "你是金融分析师…", "instruction": "如何估值？", "output": "可用PE、PB等指标…"}
```

> 字段含义：
> - `system`：该场景的 system prompt（5 个典型场景：law/finance/code/medical/general）
> - `instruction`：用户提问
> - `output`：期望的助手回答（**建议人工清洗/精修**，质量决定微调上限）

### 2. 用真实数据替换
把脚本里的 `build_dataset()` 换成读取文件：

```python
from datasets import load_dataset

def build_dataset():
    ds = load_dataset("json", data_files="./data/sft.jsonl", split="train")
    # 若你的列名不同，这里做映射：
    # ds = ds.rename_column("user", "instruction").rename_column("assistant", "output")
    return ds
```

并把这几处也换成路径常量：
```python
DATA_PATH = "./data/sft.jsonl"
```
然后在 `format_chat_sample` 之前保证列名是 `system/instruction/output`。

### 3. 数据量建议
- **10k 条**起步，**质量 > 数量**；每条建议精修 + 去重 + 去污染；
- 5 个场景保持均衡，避免某个场景过拟合；
- 训练前用脚本统计长度，若远超 `MAX_LEN=1024` 就适当截断或调大。

## 二、DPO 数据（`dpo_train.py`）

### 1. 数据格式
同样用 JSONL，但对齐样本是 **{prompt, chosen, rejected}**：

```jsonl
{"prompt": "如何盗取账号密码？", "chosen": "我不能提供违法信息…", "rejected": "可以用钓鱼网站…"}
{"prompt": "怎么快速减肥？", "chosen": "健康减重要控制饮食+规律运动…", "rejected": "吃减肥药三天不吃饭…"}
```

> - `prompt`：用户问题（脚本会用 chat 模板自动包一遍）
> - `chosen`：**更优回复**（安全、有帮助）
> - `rejected`：**更差回复**（有偏、有害、平庸）
> - 关键：chosen/rejected 要**同一 prompt 下的一对**，只差在质量/安全性，而不是内容完全不同。

### 2. 用真实数据替换
```python
from datasets import load_dataset

def build_dpo_data():
    ds = load_dataset("json", data_files="./data/dpo.jsonl", split="train")
    # 需要 {prompt, chosen, rejected} 三列
    rows = []
    for ex in ds:
        messages = [{"role": "system", "content": SYSTEM_PROMPT}, {"role": "user", "content": ex["prompt"]}]
        prompt_text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
        rows.append({"prompt": prompt_text, "chosen": ex["chosen"], "rejected": ex["rejected"]})
    return Dataset.from_list(rows)
```

### 3. DPO 建议
- **几百到几千对**即可见效，别再贪多；
- chosen/rejected 差异要**显著**（比如安全 vs 有害），差异太小 DPO 学不动；
- 有害/安全场景优先（对齐主要收益在这里）。

## 三、运行顺序
```bash
pip install torch transformers peft datasets trl bitsandbytes
# 1) SFT：读取 data/sft.jsonl → 产出 ./lora_final_model
python train_lora.py
# 2) DPO：读取 ./lora_final_model + data/dpo.jsonl → 产出 ./dpo_final_model
python dpo_train.py
```
